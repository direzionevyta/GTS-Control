# 🚀 GTS Control - Gestionale Startup

Un gestionale completo per la tua startup costruito con Streamlit e PostgreSQL.

## 📋 Funzionalità

✅ **Dashboard** - Panoramica generale dell'azienda  
✅ **Gestione Servizi** - Aggiungi e visualizza servizi  
✅ **Gestione Mezzi** - Gestisci auto, moto e altri veicoli  
✅ **Gestione Dipendenti** - Registra e visualizza dipendenti  
✅ **Gestione Turni** - Assegna turni ai dipendenti  
✅ **Fogli Viaggio** - Registra percorsi e spostamenti
